# Founder OS Design Contract

This is the shared visual contract for the Website Builder and design agents.

## Quality bar

- Build distinctive, editorial, professional interfaces instead of generic AI layouts.
- Use intentional typography, whitespace, hierarchy, and useful motion.
- Use consistent SVG icons; never use emoji as interface icons.
- Provide hover, focus, disabled, loading, empty, and error states.
- Validate 375px, 768px, 1024px, and 1440px layouts.
- Maintain readable contrast, keyboard focus, and reduced-motion support.
- Keep one primary action per viewport and put proof near claims.

## Builder workflow

Understand the business and audience, choose a visual direction, generate the design system, build reusable sections, add real assets, then review accessibility, performance, responsiveness, and conversion clarity.

Avoid decorative noise, inaccessible contrast, unbounded animation, protected content copying, and claiming external actions succeeded without a verified response.
