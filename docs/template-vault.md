# Website Template Vault

Business OS now includes a separate FreeTemplateGo collection in the Website Builder template vault.

## Included source

- Source: [FreeTemplateGo](https://freetemplatego.com/)
- Auditable repository: [making530/freetemplatego-templates](https://github.com/making530/freetemplatego-templates)
- Mirror supplied during setup: [AiXentium/freetemplatego-templates](https://github.com/AiXentium/freetemplatego-templates)
- Collection added: 20 multi-page HTML/Tailwind templates

The vault keeps metadata, live-demo links, and source links in the application catalog. It does not copy the repository's large image payload into the Business OS git repository. This keeps deployments small and lets the source remain independently auditable.

## Using a template

Open Website Builder and enable the `Template vault` section. Each FreeTemplateGo card supports:

1. `Preview` — inspect the live demo in the in-app preview panel.
2. `Source` — open the corresponding source folder on GitHub.
3. Card selection — use the template's description, styles, and component map to seed the AI brief and local draft.

These are design references and starting points. Replace demo content and imagery with original, rights-cleared assets before publishing. The source requires keeping the FreeTemplateGo footer credit according to its stated terms.
