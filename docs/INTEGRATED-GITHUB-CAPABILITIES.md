# Integrated GitHub capabilities

Founder OS reviewed and integrated the non-duplicate capabilities from the requested repositories:

- [OmniRoute](https://github.com/AiXentium/OmniRoute): optional OpenAI-compatible gateway configuration; the existing Founder OS failover remains the default.
- [website-builder-setup](https://github.com/AiXentium/website-builder-setup): guided professional website workflow, animation, responsiveness, and reusable components.
- [awesome-design-md](https://github.com/AiXentium/awesome-design-md): persistent project-level `DESIGN.md` rules for design agents.
- [ui-ux-pro-max-skill](https://github.com/AiXentium/ui-ux-pro-max-skill): design-system generation, style selection, accessibility checkpoints, and anti-pattern review.

The full upstream applications are not copied because they would duplicate runtimes and dashboards. Their useful capabilities are represented locally through the design contract, design intelligence layer, builder workflow, and gateway adapter.

Configure OmniRoute with `OMNIROUTE_BASE_URL` and optional `OMNIROUTE_API_KEY`. Leave them blank to use local/free-provider failover.
